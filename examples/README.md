# 使用示例

以下是可复制的请求，不是已经执行并通过测试的模型回答。图片、PDF 和题目文字需由使用者提供。

## 1. 从图片制作完整动画

```text
$physics-animation
请读取我附上的题目图片，记录题号和关键条件。
先独立建模再核对参考答案，制作物理过程说明、解题推导和离线 HTML。
请显示阶段分析、相关曲线、可调独立参数、事件时间线和暂停批注。
对实际测试范围如实记录。
```

## 2. 先确认物理过程

```text
$physics-animation
先分析这道题的约束、受力、守恒成立条件和阶段事件，给出完整推导。
写出可视化设计，说明每个关键关系将如何被观察和验证。
这次先不要制作动画，等我确认模型。
```

## 3. 明确条件的简谐运动

```text
$physics-animation
水平光滑面上，一个质量 m 的物块与固定端轻弹簧连接，劲度系数 k。
从平衡位置右侧 A 处由静止释放，不考虑阻力，向右为正方向。
制作两个完整周期的动画，展示位置、速度、加速度、弹簧力和能量转换。
保留符号解，数值只作为标明的演示值。允许改变 m、k、A，显示各自影响。
```

## 4. 检查电磁感应中的抵消

```text
$physics-animation
针对我提供的线框题，先判定回路是否闭合、磁场如何随时间和位置变化。
推导感生与动生电动势，展示各项符号、总量和两边安培力的合量。
用同一模型计算反馈运动，不把各项相加的关系画成虚假的时间延迟。
请专门验证“分项非零但合量为零”是否适用。
```

## 5. 修改已有动画

```text
$physics-animation
请检查我提供的 HTML 及模型文件。
我希望看清临界时刻前后的变化，加入事件定位和必要的局部放大。
保留有用曲线和完整推导，不新增独立的规律分解导航。
如果原模型存在物理错误，先解释错误及受影响结果，再修复。
```

若宿主缺少浏览器或手写笔测试条件，应明确写“未测试”，不能把代码检查当作真实操作验证。
