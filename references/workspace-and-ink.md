# 工作台与暂停帧批注

## 阶段数据（新题必需）

`model.lessonSteps(sim)` 返回按时间排序的数组，严格交替 `state, process, state, …, state`。至少初态、过程、终态三项，每项有：

- `id`：唯一稳定 ID，供左栏和时间节点共用。
- `kind`：`state` 或 `process`。
- `start,end`：真实物理秒；state 两者相同；process 从前一状态时间到后一状态时间，长度大于零。
- `title,text,equation`：非空中文标题、具体过程分析与适用公式；来自本题推导及 sim，不能复制无关题的文字。

起点为 0、终点为 sim.duration。修改参数后重新构建。合并同时发生的事件，避免零长度过程；分别说明瞬时跳变的左右极限。时间线的编号标记对应状态、区间条对应过程，点击区间定位中点。自动模式显示已到达的步骤并展开当前项；手动模式自由展开全部，点击“定位”才改变时间。

对指数衰减等无有限终态的问题，最后一个状态写“观察终点”，说明真正极限条件；不能把 6τ 写作完全停止。教学采样节点不是新的力学阶段，标题应明确其含义。

`scripts/check_model.cjs` 检查交替顺序、连接关系、范围、唯一 ID 与必填内容；文字是否正确、是否覆盖关键规律仍由作者核验。兼容旧模型的界面回退只供迁移，新交付必须实现独立的 lessonSteps。

## 可复用界面

- `workspace.js` 复用 runtime 的 DOM，建立左侧分析、中央模型/曲线、右侧参数、底部操作布局。保留完整推导，不创建独立规律分解分区，可通过顶部按钮独立开合，专注模式记住进入前的可见分区。
- `runtime.js` 提供内部 `physicsUI`：pause、seek、jump（同步事件锚点）、restore(params,time)、kit 和只读 sim/time/params；在时间变化和参数重建后分别发出 `physics:time`、`physics:rebuild`。
- 新监听器不得向模型添加另一套物理计算。界面联动使用 sim.state、model.present、model.lessonSteps。

## 批注与保存语义

`annotations.js` 是原生 Canvas / Pointer Events 实现。进入批注先暂停并在同一调用中渲染和截取 WebGL 画面，禁用 TrackballControls。采用归一化笔迹坐标；暂停底图与笔迹保持同一宽高比，改变窗口或折叠面板时整体缩放/留边。笔迹不会随物体或相机继续运动。

每帧保存暂停截图、物理时间、参数、笔迹操作序列。橡皮擦使用 destination-out；撤销/重做恢复序列后重绘。恢复批注帧会恢复其模型参数和时间，并展示原来的暂停截图；点击“返回模型”回到可旋转实时画面。更换参数、时间或视角会退出批注层。

默认每笔结束立即写 localStorage，不依赖 beforeunload。保留开关关闭时立即删除持久副本，仅在内存中保留到页面关闭。用户可清空本帧、删除本帧或清空全部；全部清空使用页面确认防止误触。存储失败不得显示保存成功：提示导出，笔迹仍可继续使用，必要时触发浏览器标准离开提示。

导出 JSON 包含完整暂停图和笔迹，可重新导入本题并合并；导入检查版本、题目、有限数、参数合法性、笔迹结构和大小。不执行导入数据中的 HTML 或脚本。限制最多 60 帧、导入文件最多 40 MB，并显式报错；实际 localStorage 配额由浏览器决定。

本地 file:// 页面存储在不同浏览器的行为不保证一致，搬动文件、换浏览器或清理数据可能无法找回；“导出批注”是可携带备份。不声称批注改写了原 HTML，也不声称跨设备同步。当前覆盖模型画面手写批注，不包含完整白板的课件编辑、联网协作或手写识别。

## 验收重点

在真实浏览器使用鼠标拖画，检查相机未移动；橡皮擦后读取图像 alpha 或观察截图确认擦除，而不是只检测操作计数。测试撤销恢复、重载、清空策略、导出导入、缩放保持底图对齐；用浏览器触控输入补充验证，并注明未进行真实触屏/手写笔硬件测试。保存失败可模拟存储额度拒绝，确认页面仍能导出。
