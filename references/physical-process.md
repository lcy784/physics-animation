# 物理过程说明

此文档供用户核对模型，也是动画实现依据。按题目需要展开，不为空字段编造内容。

## 建议内容

1. **原题定位与识别**：文件/图片、PDF 物理页码、题号、小问；易混符号、图线读数、未解决歧义。未核验时不把汇编标题当官方认证。
2. **关键条件解释**：条件原意 → 物理约束 → 对方程/阶段的影响。参考答案结论单列，不混进题设。
3. **对象与初态**：系统边界、参考系、坐标正向、SI 单位、位置/速度/场/边界；未给数值用符号或明确演示值。
4. **方程及适用条件**：受力/约束、运动/场方程、守恒关系；每个规律说明系统和时间区间。图线倒推参数时区分独立输入和结果。
5. **阶段表**：起止事件、状态方程、触发函数、切换后模型、连续量与允许跳变量。事件左/右极限必须明确。
6. **解题过程**：逐小问列出从初态到目标的计算链、解析答案、必要特例与答案比对；不以仿真数值代替证明。
7. **参数规则**：默认值及来源、可调范围、依赖关系、约束保持/自由探索、改动后重算策略。
8. **显示映射**：模型量 → 画面/曲线/数值；说明缩放、示意几何、放慢事件。相机坐标与物理坐标区分。
9. **核验与边界**：守恒/平衡残差、极限、事件前后、数值收敛、参考答案差异；明确停止时刻与未建模过程。

## 常见关键点

- 接触力只能推不能拉；绳只在绷紧时约束距离；未连接弹簧恢复原长后不再拉动物体。
- 相对速度为零决定相对位移极值；绝对速度可以非零。
- 动量守恒必须排除该方向的外冲量；机械能变化需计入外功、耗散或释放机构。
- 电磁题先定回路、正方向和磁通；磁通正负、变化率和电流方向不可混写。
- 几何临界、静摩擦上限、碰撞、开关事件改变可用方程，不能继续延长旧解。
- “最终”可能是有限时刻，也可能是渐近极限；不得把阈值截断声称为精确终态。
- 参考答案疑似有误时用可检验关系定位差异，保留原文，说明受影响结论。
